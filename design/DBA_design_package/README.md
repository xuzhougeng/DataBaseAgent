# DBA 页面设计资料包

DataBaseAgent（DBA）：围绕研究主题构建数据库的本地智能体工作台。

本包整理于 2026-11-05，包含此前设计稿的完整 HTML、CSS、JavaScript，以及需求和页面说明。它是可交互的前端原型，不是已经实现远程计算的桌面应用。

## 打开方式

解压后用浏览器打开 `index.html`。所有样式、图标、示例数据和交互代码均内嵌于该文件，无需安装前端依赖，也没有外部资源引用。

如浏览器限制本地文件保存状态，可在本目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8000 。Windows 也可使用 `py -m http.server 8000 --bind 127.0.0.1`。按 Ctrl+C 关闭服务。

在线设计稿：https://dba-workbench-design.hoptop.chatgpt.site

## 文件清单

- `index.html`：完整可编辑设计稿，包含 9 个主要页面。
- `docs/需求与页面说明.md`：产品目标、页面清单、交互路径及开发衔接建议。
- `SHA256SUMS.txt`：包内源文件和文档的 SHA-256 校验值。

## 建议体验路径

1. 从「所有项目」新建项目，或切换到 GPSA 示例项目。
2. 在「主题与检索」编辑检索策略，在「数据复核」查看依据并确认纳入或排除。
3. 在「处理流程」解锁、编辑工具和参数，再锁定流程。
4. 在「运行任务」查看任务记录，打开求助弹窗并补充样本分组。
5. 在「服务器资源」保存示例配置，在「数据与产物」预览并导出演示清单。

## 状态与限制

部分交互状态写入浏览器 localStorage，键名为 `dba-design-v1`。同一浏览器、同一来源下可保留部分修改；文件打开与 HTTP 服务是不同来源。需要恢复初始状态时，可在浏览器开发者工具中删除该键并刷新。

所有检索、任务进度、服务器指标、自动修复和产物均为模拟。新建项目可演示独立的检索、复核与流程设置，但完整任务与产物示例主要集中在 GPSA 项目。部分统计和时间线是固定展示值，不代表完整业务状态联动。原型没有真实文献接口、SSH、调度器、持续巡检、模型调用或后台数据处理。
