- PubMed 真实 API 当次返回 HTTP 500；Europe PMC 的一次复合查询返回 HTTP 503，后续简单查询成功。错误已记录，未伪造候选记录。GEO 尚未进行真实网络联调。
- 调度、恢复和归档测试使用可控执行器；没有配置真实 SSH 服务器，也没有实际执行研究分析流程。
- 模型请求与证据校验通过受控 HTTP 响应验证；没有配置或调用真实模型账号。
- 验收工作空间位于 `.tmp/`，不随成品分发；应用默认从空工作空间开始。
